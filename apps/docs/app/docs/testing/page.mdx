# Testing

## Inject a fake client

`config.client` accepts anything shaped like an `S3Client`, so a stub that records the commands it
receives is enough to test your own upload paths:

```ts
import type { S3Client } from '@aws-sdk/client-s3'
import { createBucket } from 'bucketcode'

function fakeBucket() {
  const calls: { name: string; input: Record<string, any> }[] = []

  const client = {
    send: async (command: any) => {
      calls.push({ name: command.constructor.name, input: command.input })
      return { ETag: '"stub"' }
    },
  } as unknown as S3Client

  return { bucket: createBucket({ bucket: 'test', client }), calls }
}
```

```ts
it('uploads the avatar under the user id', async () => {
  const { bucket, calls } = fakeBucket()

  await saveAvatar(bucket, 42, new File(['x'], 'me.png', { type: 'image/png' }))

  expect(calls[0].input.Key).toBe('avatars/42')
  expect(calls[0].input.ContentType).toBe('image/png')
})
```

A stub covers `upload()`, `put()`, `get()` and `delete()`. It does **not** cover `getUrl()`, which
signs with the real SDK — see below.

## Faking get()

`get()` reads the SDK's stream helpers off the response body, so a stub for it returns those two
functions:

```ts
const client = {
  send: async () => ({
    Body: {
      transformToByteArray: async () => new TextEncoder().encode('hello'),
      transformToString: async () => 'hello',
    },
    ContentType: 'text/plain',
    Metadata: { filename: 'greeting.txt' },
  }),
} as unknown as S3Client
```

To test the missing-file path, throw the error S3 raises:

```ts
const client = {
  send: async () => {
    throw Object.assign(new Error('no such key'), {
      name: 'NoSuchKey',
      $metadata: { httpStatusCode: 404 },
    })
  },
} as unknown as S3Client

expect(await bucket.get('XK5892')).toBeNull()
```

## Testing signed URLs

Signing is a local computation, so it needs credentials but no network. Pass static ones:

```ts
const bucket = createBucket({
  bucket: 'test',
  region: 'eu-west-3',
  credentials: {
    accessKeyId: 'AKIAIOSFODNN7EXAMPLE',
    secretAccessKey: 'wJalrXUtnFEMI/K7MDENG/bPxRfiCYEXAMPLEKEY',
  },
})

const url = new URL(await bucket.getUrl('a.txt', { expiresIn: 60 }))

expect(url.searchParams.get('X-Amz-Expires')).toBe('60')
expect(url.searchParams.get('X-Amz-Signature')).toBeTruthy()
```

## Against a real bucket

For an integration test that exercises the actual protocol, run MinIO and point bucketcode at it.
See [S3-compatible providers](/docs/providers) for the container command. It catches the class of
bug a stub cannot: checksum headers, path style, content-type round-trips.
